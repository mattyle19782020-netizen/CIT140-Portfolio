# Week 6 - Cedar Junction - Data-Flow Model (50 points)

Question: where does the information go? Follow one drone inspection report
from the field to the receiving department, and explain the routing problem
using the records.

The report was ACCEPTED by the routing system, but the department that needed
it did not receive it. The finding comes from comparing the EXPECTED
destination against the OBSERVED destination.

## The three pages

1. SYSTEM BOUNDARY - one system, the external teams, labeled inputs and
   outputs, and what is inside versus outside scope.
2. INFORMATION MOVEMENT - four processes, two data stores, connected and
   labeled data flows. External flows MUST match page 1 exactly.
3. DATA DEFINITIONS AND FINDING - define ALL EIGHT supplied fields, explain
   one report's expected versus observed destination, cite the sources, and
   name one unanswered question.

## Rubric, 10 points each, 50 total

- R1 Use the evidence
- R2 Show the system boundary

Scoring is binary per requirement: 10 if met, 5 if substantially unmet.
There is no partial credit between, so a single substantial omission under
any R-number costs 5 points.

## Traps to avoid

- Page 2 external flows disagreeing with page 1. Same teams, same labels.
- Defining only some of the eight fields. All eight.
- Recommending a fix. This is still current-state analysis plus ONE finding.
- Stating the cause of the misrouting as fact if the records only show the
  symptom. Mark the unanswered question instead.
